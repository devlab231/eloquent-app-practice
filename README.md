# eloquent-app-practice

## 概要
COACHTECH 教材 Tutorial 9-4「Eloquent ORM ハンズオン演習」で作成した成果物です。<br>
LaravelとEloquent ORMを使用して、ブログ投稿の一覧表示・新規作成・編集・削除（CRUD）ができるWebアプリを作成しました。

## 使用技術
- PHP 8.5.12
- Laravel 10.50.3
- Eloquent ORM
- MySQL

## 学んだこと
- Eloquent ORMを使用したデータの取得・登録・更新・削除
- all()、create()、update()、delete()によるデータ操作
- マスアサインメント対策やバリデーションの必要性

## 動作確認
GitHubから本プロジェクトを取得し、Laravel Sailを使用して起動することで動作確認できます。<br>
ブラウザで投稿一覧ページが正常に表示されることを確認してください。<br>
※ 実行にはDocker環境および初期設定が必要です。<br>
